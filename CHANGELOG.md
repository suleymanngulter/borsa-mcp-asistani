# Changelog

Tüm önemli değişiklikler bu dosyada belgelenecektir.

Format [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) standardına göre,
ve bu proje [Semantic Versioning](https://semver.org/spec/v2.0.0.html) kullanır.

## [1.0.0] - 2026-03-08

### Added
- MCP server ile BIST ve TEFAS takip sistemi
- HTTP REST API server (FastAPI)
- 15 MCP tool ile kapsamlı özellikler
- Watchlist yönetimi (ekleme, silme, güncelleme)
- Gerçek zamanlı fiyat takibi (yfinance ve TEFAS crawler)
- Eşik bazlı uyarı sistemi
- Günlük portföy raporları
- Gemini AI ile piyasa analizi
- Geçmiş fiyat verileri saklama
- Paralel işleme optimizasyonu
- E-posta bildirimleri (SMTP)
- Telegram bildirimleri
- Otomatik scheduler
- CSV/JSON export özellikleri
- Grafik görselleştirme (matplotlib)
- Kapsamlı test suite (pytest)
- Detaylı dokümantasyon (README ve kullanım kılavuzu)

### Technical
- Python 3.8+ desteği
- SQLite veritabanı
- Type hints
- Comprehensive logging
- Error handling ve retry mekanizması
- Environment variable yapılandırması
- .gitignore ve .gitattributes
